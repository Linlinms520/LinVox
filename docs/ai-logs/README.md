# AI 使用痕迹存档

存放 AI 辅助开发的原始记录，作为人工智力投入的证据链。

## 放什么

按次归档，一个功能点一个文件：

```
docs/ai-logs/
├── 2026-09-20_窗口与主题.md
├── 2026-09-22_实时变声页.md
└── 2026-09-25_打包与安装包.md
```

每个文件至少写清四件事：

1. **日期**
2. **模型名与版本**（模型更新后相同输入不可复现，必须记版本）
3. **关键 prompt**（原始输入，不要只写结果摘要）
4. **人改了什么**（AI 初稿 → 人修改 → 定稿的差异）

## 怎么拿

- AI 平台提供导出功能的，直接导出原始对话放进这里
- 不提供导出的，把关键轮次的 prompt 与答复**手工贴进来**
- 聊天记录太长时截取关键片段，但**保留前后文**（能看出迭代链条）

## 注意

- 记录里不要贴密钥、绝对路径、内网地址 —— 存档同样是公开仓库的一部分
- 本目录只放文本（`.md` / `.txt`），不要放截图和附件
- 本文件用于保住目录本身（Git 不跟踪空目录）
